Gmail 专用：用 Google 账号授权，不需要应用密码
未授权
  1. 打开 新建项目，名字随便填（如 leadradar）；创建后确认左上角选中的是这个项目
  2. 打开 Gmail API，点「启用」
  3. 打开 OAuth 同意屏幕：选「外部」→ 填应用名和你自己的邮箱 → 保存；在「测试用户」里把要用的 Gmail 加进去
  4. 打开 凭据 → 创建凭据 → OAuth 客户端 ID → 类型必须选 桌面应用 → 创建
  5. 把弹窗里的 客户端 ID 和 客户端密钥 粘到下面，点保存
  6. 回来点「用 Google 账号授权」，在浏览器里登录并点「继续 / 允许」
同意屏幕停在「测试」状态时，Google 的授权 7 天会过期——到时点一次「重新授权」就行。想长期有效，可在同意屏幕点「发布应用」（会提示未验证，自己用可以继续）。

中文关键词 → 本地语 （建议先走这一步）
中文直接写，一行一条，例如「跑步压缩裤 批发」。会按目标国家的真实搜索习惯翻成本地语言，不是直译——韩国出「압축 레깅스 도매」，泰国出「กางเกงรัดกล้ามเนื้อ ขายส่ง」，印尼出「celana compression grosir」。
只跑搜索，不抓官网、不写报告、不进跨天去重库。试跑的是下面「自定义检索式」当前框里的内容，含未保存的改动——换词前先用它看效果。
一行一条，按顺序铺满「产品 × 市场」。可用占位符：{product} 产品词 · {buyer} 买家类型词 · {country} 国家词。
这是唯一能写「本地语言」和「site: 限定」的入口，比模板更精准。
上限含社媒检索式，按次计费，调大前先看成本。
