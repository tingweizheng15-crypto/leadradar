## 使用

在客户工作台顶部输入搜索词，每行一个，勾选目标国家。默认开启“按国家扩展当地语言，同时保留原词检索”。点击“预览多语言搜索词”，可以看到各国译词、译词来源和实际搜索查询；在展开区域可直接修改译词，每行对应一个原词。

“保存搜索词”会保存原词、国家、多语言开关及手动译词，定时任务也会使用。“开始搜索”会立即按当前输入运行。预算仍受配置中的总搜索次数限制；预算不足时不能保证每个词、国家、语言与渠道的全部组合都覆盖。

常见服装词使用内置多语言词库；其他词使用已配置的大模型翻译，并在本机缓存30天。没有模型或翻译失败时，界面会提示，保留原词并允许手动填写当地语言。修改原搜索词会清理旧的手动对应关系，避免使用错位译词。

搜索返回的当地语言网页也能用对应译词核验产品证据，已补充泰语、印尼语、马来语、韩语的部分品牌/分销/采购表述。模型和词库翻译不代表采购事实，公司的采购意向仍需复核。
